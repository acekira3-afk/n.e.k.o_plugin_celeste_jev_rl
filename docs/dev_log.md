# 开发日志

## 2026-09-22 — 三段式 Think-Execute 架构完成

### 今日完成

将蔚蓝 Jev RL 插件从"帧级 DQN 控制"重构为**三段式 Think-Execute 架构**：感知 → 思考 → 执行。核心思路来自用户的观察：蔚蓝的像素级操作可以通过编写帧精确操作脚本实现，Jev 负责判断当前状况选择对应脚本，Jev 的延迟反而成为"角色思考时间"。

### 关键设计决策

#### 1. 从"逐帧决策"到"情境-脚本映射"

之前的问题是：Jev 延迟 70-500ms，蔚蓝需要 16ms/帧的精度，根本来不及。

新方案：Jev 不选单帧动作，而是**识别当前情境**（冲刺间隙？蹬墙上升？尖刺走廊？），然后选择对应的**帧精确操作脚本**执行。这完全符合速通者的实际操作模式：看一眼障碍布局 → 想一下该用什么技巧 → 一套搓完。

#### 2. Jev 延迟从缺陷变成特性

之前：Jev 500ms 太慢
现在：Jev 500ms = "角色思考了 0.5 秒"，加上 0.3-1.0s 的拟人思考暂停，完全合理。N.E.K.O 人格层在这段时间显示 thinking 表情和独白文字。

#### 3. N.E.K.O 人格层让 AI 变成"角色"

- 9 种 Live2D 表情（thinking/focused/panicked/happy/frustrated 等）
- 独白系统（"前方有尖刺...得先跳上去"）
- 位置记忆（"上次在这选了 dash_across_gap 失败了，试试 wall_jump_climb"）

## 2026-09-22（早） — 初始版本

### 完成内容

创建了 N.E.K.O 插件骨架，包含：

- 插件清单 `plugin.toml`（配置项、入口、依赖）
- Jev 决策层（4 层目标层级：战略→战术→动作→原子）
- DQN 训练层（4 层网络 + 经验回放 + 目标网络）
- Jev 奖励塑形器（危险惩罚 + 质量奖励）
- 实验调度器（4 模式对比：jev_only / dqn_only / jev_shaped_dqn / jev_router_dqn）
- 状态编码器（26 维数值 → 结构化文本）
- 12 个单元测试
- CI/CD workflow
- 详细实验方案文档

### 核心问题

帧级 Jev 控制不可行：70-500ms 延迟 > 16ms/帧需求。需要分层设计让 Jev 做高层决策，DQN 做底层执行。但这仍然需要训练 DQN。

### 转折

用户提出：蔚蓝的像素级操作可以通过**编写操作脚本**实现，现在状况判断进行延迟输入一系列操作，像是人物反应思考一段时间后的操作。这个思路直接绕过了"Jev 延迟太高"的问题，将延迟转化为特性。
